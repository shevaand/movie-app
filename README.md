# Movie App

A modern movie discovery application built with React and TypeScript using the TMDB API.

The application allows users to browse popular, top-rated, and upcoming movies, filter and sort movies, and view detailed information about each movie.

## Features

- Browse popular movies
- Browse top-rated movies
- Browse upcoming movies
- Filter movies by rating
- Sort movies by rating
- Sort movies by release date
- Ascending and descending sorting
- Movie detail pages
- Movie posters and backdrops
- Movie genres
- Movie overview
- Movie budget
- Movie runtime
- Top cast
- Official YouTube trailers
- Loading states
- Responsive UI
- Dark mode

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Lodash
- CSS
- TMDB API

## API

This project uses the [TMDB API](https://www.themoviedb.org/documentation/api) to retrieve movie information.

The application uses TMDB data for:

- Movie lists
- Movie details
- Ratings
- Release dates
- Genres
- Cast
- Movie images
- Trailers
